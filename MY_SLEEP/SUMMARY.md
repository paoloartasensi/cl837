### Critical Fix Applied: UTC Conversion
```dart
// The fix that changes everything:
DateTime timestamp = DateTime.fromMillisecondsSinceEpoch(
  utcSeconds * 1000,
  isUtc: true,      // ← THIS IS CRITICAL!
```
